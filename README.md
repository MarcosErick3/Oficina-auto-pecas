# 🚗 AutoPrime | Oficina & Auto Peças

Landing page moderna e responsiva criada como **protótipo comercial para uma oficina mecânica e loja de auto peças**.

## 🌐 Demonstração

**GitHub Pages:** https://marcoserick3.github.io/Oficina-auto-pecas/

## ✨ Funcionalidades

- Hero section com chamada para orçamento
- Apresentação dos principais serviços automotivos
- Seção de auto peças
- Área institucional
- Indicadores de confiança
- CTA integrado ao WhatsApp
- Layout responsivo para desktop, tablet e celular
- Navegação por âncoras
- Estrutura preparada para personalização para clientes reais

## 🛠️ Tecnologias

- HTML5
- CSS3
- Google Fonts
- Design responsivo
- WhatsApp CTA

## 🎯 Objetivo do projeto

Este projeto faz parte do portfólio de **Marcos Medeiros** e foi desenvolvido para demonstrar como uma oficina ou auto peças pode apresentar seus serviços de forma profissional na internet e transformar visitantes em solicitações de orçamento.

## 📱 Responsividade

O layout foi desenvolvido para funcionar em diferentes tamanhos de tela, com adaptações específicas para dispositivos móveis.

## ⚠️ Projeto demonstrativo

Os dados apresentados no site, incluindo nome da empresa, telefone, avaliações, experiência, horários e demais informações comerciais, são **fictícios** e devem ser substituídos antes da utilização em um cliente real.
